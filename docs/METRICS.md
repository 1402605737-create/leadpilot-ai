# LeadPilot AI 指标体系

## 北极星指标

**Qualified Meetings Booked per Week**：一周内完成资格确认且已预约的首次销售会议数量。它直接连接用户价值与 pipeline 结果。

## 输入指标

| 指标 | 定义与计算 | 业务意义 |
|---|---|---|
| ICP Coverage | 符合当前 ICP 的线索 / 总线索 | 判断可触达市场质量 |
| Evidence Completeness | 拥有行业、规模、联系人和信号的线索占比 | 防止低证据自动化 |
| A-grade Leads | 总分达到 80 的线索数 | 衡量可立即行动的账户池 |

## 过程指标

| 指标 | 定义与计算 | 业务意义 |
|---|---|---|
| Drafts Reviewed | 被人工确认的草稿数 | 衡量安全工作流采用 |
| Replies Classified | 完成分类的回复数 | 衡量回复处理效率 |
| Research Time Saved | 线索数 × 规则基准研究时间 | 衡量 SDR 效率提升 |

## 结果指标

| 指标 | 定义与计算 | 业务意义 |
|---|---|---|
| Positive Reply Rate | Interested 回复 / 总回复 | 衡量触达相关性 |
| SQL Conversion Rate | 合格会议 / 总线索 | 衡量漏斗效率 |
| Pipeline Generated | 合格会议 × 估算机会金额 | 连接产品动作与收入 |

## 风险指标

| 指标 | 定义与计算 | 业务意义 |
|---|---|---|
| Unreviewed Sends | 未人工确认的外部发送数，目标恒为 0 | 核心合规红线 |
| Rejection Re-contact | 拒绝后再次触达数，目标恒为 0 | 保护客户体验与合规 |
| AI Fallback Rate | fallback=true 的模型运行 / 总运行 | 监控真实模型可靠性 |
