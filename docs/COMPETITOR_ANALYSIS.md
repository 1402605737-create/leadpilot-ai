# 竞品与机会分析

| 产品类型 | 代表产品 | 擅长领域 | LeadPilot AI 的机会 |
|---|---|---|---|
| CRM | Salesforce、HubSpot | 客户记录、流程、报表和生态 | 不替代 CRM，聚焦冷线索到首次合格会议的执行闭环 |
| Conversation Intelligence | Gong | 通话与会议信号、教练和预测 | 将会前研究、回复处理和会议准备连成轻量工作流 |
| Prospecting Data | Apollo | 联系人数据与销售触达 | 在数据之上提供可解释优先级和受控 Agent 行动 |
| Sales Engagement | Outreach、Salesloft | 序列、任务和销售执行 | 默认 human-in-the-loop，避免无人监督自动发送 |

LeadPilot AI 的切入点是轻量、可解释、面向中小 B2B 团队，并以 Qualified Meetings Booked per Week 衡量结果。它强调 Agent 的证据、步骤和审批状态，而不是只提供聊天界面或批量内容生成。
