# LeadPilot AI PRD

## 背景与用户

LeadPilot AI 服务 SDR、BD、AE、销售经理与 RevOps。中小型 B2B 团队通常拥有大量线索，却缺少研究、优先级判断、个性化触达、回复处理和 CRM 更新的统一工作流。

## 产品目标

以“每周新增合格销售会议数”为北极星指标，缩短线索研究时间，提高优先账户的有效回复和会议转化，同时确保所有外部动作经过人工确认。

## MVP 范围

- ICP 设置和确定性商机评分。
- 线索池、账户情报、触达草稿、回复分类、会议 brief 和 CRM 更新建议。
- 收入与漏斗看板、Agent Activity、审计日志。
- DeepSeek 真实调用与规则 fallback。

不做真实邮件发送、LinkedIn 自动化、通用 CRM、自动报价或无人监督的外部动作。

## 核心流程

配置 ICP → 选择高分线索 → 查看证据和情报 → 生成并人工审核触达草稿 → 分类回复 → 准备会议 → 生成人工审核的 CRM 更新 → 衡量合格会议和 pipeline。

## 权限与合规设计

- 消息不能自动发送，只能复制或标记为待人工确认。
- 拒绝和退订意向触发停止触达。
- Agent 仅接受固定任务和已知 lead ID，不接受任意 prompt。
- 保存模型、fallback、证据、步骤和结果，形成审计链。
- 生产 API 使用精确 CORS allowlist、请求大小限制和速率限制。
- 共享 Supabase 项目内使用独立 `leadpilot` Schema、独立 `leadpilot_app` 角色和表级 RLS；应用查询始终显式引用完整表名。
